✨ NEW PYTHON POWER: DIFFERENT OBJECTS, DIFFERENT ABILITIES

  

   
You're starting to see how object-oriented Python works: different kinds of objects can store different information and do different things.

   

    
🌸 Flower(...)Creates a Flower object with flower properties.

    
🦋 Butterfly(...)Creates a different kind of object with butterfly properties.

    
🪽 Propertieswing_colour, dot_colour, size and sparkle describe the butterfly.

    
🛠️ MethodsA flower uses .draw(). A butterfly uses .fly(). Methods are actions an object knows how to perform.

    
📍 Coordinatesx and y position objects inside the same garden world.

    
🧠 Combining conceptsYou're now using objects, variables, parameters, loops, lists and randomness together.
