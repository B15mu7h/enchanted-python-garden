✨ NEW PYTHON POWER: FUNCTIONS

  

   
A function lets you give a group of instructions a name. Once it exists, you can reuse those instructions whenever you want.

   

    
🪄 defShort for “define”. It tells Python you're creating a new function.

    
🏷️ fairy_flowerThe name YOU gave your new command.

    
📥 Parameterscolour, x and y are information the function receives.

    
↘️ Function bodyThe indented instructions are what Python performs whenever the function is called.

    
📞 Function callfairy_flower("#ff86d3", 25, 72) actually runs your reusable code.

    
♻️ ReuseChange the function once and every future call uses the updated instructions.

🧠
Code Detective · Function vs call
What is the difference between def fairy_flower(...) and fairy_flower(...)? One creates the command; one uses it.

   
💡 Big idea: Functions stop us repeating ourselves. Instead of copying the same code again and again, we package it into a reusable command.
